# SRCH-05 ① 작성자 닉네임 검색 · MY-05 공개 프로필

## 기능정의서 반영 문구

작성자 닉네임 검색은 공개 프로필 조회와 동일하게 `member.status = ACTIVE`인 회원만 노출하며, 탈퇴(WITHDRAWN)·삭제(DELETED) 회원은 제외한다.

이 문구는 공식 기능정의서 MY-05에 반영하고 SRCH-05 ①에서 참조할 기준이다. 외부 공식 시트는 아직 수정하지 않았다.

공식 시트는 새 행을 만들지 않고 기존 MY-05 행의 ①~③을 보존하여 다음 내용을 덧붙인다:

> ④ 공개·검색 노출 기준: ACTIVE 회원만 공개 프로필 및 작성자 닉네임 검색에 노출한다. 탈퇴(WITHDRAWN)·삭제(DELETED) 회원은 제외한다.

SRCH-05 담당자는 기존 ①의 작성자 검색 항목에 MY-05 ④ 참조, 정확 일치 우선·나머지 ID 오름차순·최대 50명, 빈 목록일 때 제목·본문 검색 유지 조건을 반영한다. 공모전·모집글·게시판 검색 및 ② 통합 랭킹 내용은 유지한다.

## 호출 계약

다른 도메인은 `MemberService.findActiveMemberIdsByNickname(String keyword)`를 호출한다.

- 반환: `List<Long>`, 최대 50명, 닉네임 정확 일치 우선 후 회원 ID 오름차순. 정렬을 DB에서 적용한 뒤 50명으로 제한한다. 일치하는 회원이 없으면 빈 목록.
- 앞뒤 공백 제거 후 닉네임 부분 일치, 영문 대소문자 구분 없음.
- null·빈 값·2자 미만은 빈 목록 반환. `%`·`_`는 검색 와일드카드가 아닌 문자로 처리한다.
- DB 조회 자체를 50명으로 제한하며 전체 회원 엔티티나 이메일을 반환하지 않는다.
- 로그인 잠금·일시 정지는 기존 공개 프로필 조회와 동일하게 별도 제외 조건으로 추가하지 않는다. ACTIVE 여부가 기준이다.
- 검색 호출자는 빈 ID 목록이면 작성자 일치 분기만 제외하고 제목·본문 검색은 유지한다. 전체 회원을 작성자 조건으로 조회해서는 안 된다. 50명을 초과하는 닉네임 일치는 잘리므로 전체 일치 회원 수를 보장하지 않는다.

회원 서비스와 저장소에만 추가한다. 검색 API·검색 화면 연결은 SRCH-05 담당자가 진행한다. DB 변경·마이그레이션은 없다.
