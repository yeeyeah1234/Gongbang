# #148 관리자 게시글 신고 처리

- 관리자 `/admin/reports`에 `BOARD_POST` 필터·대상 표시·`HIDE_BOARD_POST` 조치를 추가한다.
- 기존 신고 상세 응답에 `deletedAt`을 추가한다. 관리자만 삭제 원문과 삭제 시각을 조회한다. 일반 게시글 목록·상세에서는 기존 소프트 삭제 필터를 유지한다.
- BoardPostModerationService.target(actor,id)/hide(actor,id)는 관리자 권한을 검사한다. hide는 게시글 행 잠금을 잡고 최초 한 번만 deleted_at을 설정한다. 여러 신고가 같은 글을 가리켜도 재삭제는 성공으로 처리하며 기존 삭제 시각은 보존한다.
- 관리자 신고 심사는 기존 신고 행 잠금과 처리 완료 중복 거부를 유지한다. 게시글 숨김 실패 시 신고를 RESOLVED로 바꾸지 않는다.
- #160 병합 후 ReportTargetType·ReportTargetValidationService와 테스트는 develop 기준으로 통일했다. 신고 접수는 BoardPostQueryService.getActivePost로 활성 글과 작성자를 검증하며, 중복 BoardPostModerationService.reportAuthor는 제거했다. 관리자 조회·숨김만 별도 서비스에 유지한다.
- SPAM/INAPPROPRIATE 사유 추가·일반 회원 신고 모달·PostModerationSection 공통화는 건우님 작업, BoardDetailPage 신고 버튼 연결은 수형님 작업으로 남긴다. 관리자 화면은 두 추가 사유의 한글 표시를 준비했다.
- DB 구조 변경 없음. report.target_type=BOARD_POST와 action=HIDE_BOARD_POST, 상세 응답 deletedAt은 공식 API·DB 명세에 반영 필요.
