# 관리자 제재 후속 정책

사용자 요청(2026-11-25)에 따라 기존 제재를 다음과 같이 확장한다. 공식 기능·API·DB 시트에는 별도 반영이 필요하다.

- 관리자 대상 회원 제재·잠금 해제는 서버에서 금지한다. 일반 회원에게 관리자 권한을 부여하는 기존 기능은 유지한다.
- 닉네임 변경 요구: 알림은 `/mypage/nickname`으로 연결한다. 변경 전에는 내 정보 조회·닉네임 변경·로그아웃만 허용하고 나머지 인증 API와 STOMP 사용을 차단한다. 기존 닉네임과 대소문자만 다른 이름도 사용할 수 없다.
- `blocked_nickname`: nickname VARCHAR(10) PRIMARY KEY, created_at DATETIME DEFAULT CURRENT_TIMESTAMP. MySQL utf8mb4_0900_ai_ci 비교로 제재된 이름을 영구 예약한다. 가입·중복검사·프로필 변경에 공통 적용한다. V33으로 생성하고 기존 변경 요구 회원을 초기 등록한다.
- 경고·정지·정지 해제·닉네임 변경 요구는 사이트 알림과 이메일 대기열에 기록한다. 기존 이메일 야간 보류·일일 제한 정책은 유지한다.
- 기간 정지는 미래 종료 시각 필수, 무기한은 `SUSPEND_PERMANENT` 요청을 `suspended_until=9999-12-31 23:59:59`로 저장한다. 해제는 기존 UNSUSPEND. 정지 시 모든 refresh 토큰 폐기, 기존 access 토큰도 요청마다 차단한다.
- 화면은 로그인 중 30초마다 본인 상태를 확인하고 정지 시 로그인으로, 변경 요구 시 전용 화면으로 이동한다. 서버는 다음 요청부터 즉시 차단하며 화면 이동은 통신 지연에 영향을 받는다.
- 신고 상세는 신고자·처리자·대상 작성자의 닉네임과 대상 내용을 표시한다. 필터 결과 0건은 해당 유형 신고 없음으로 표시하고 전체 필터 복귀를 제공한다. 다른 유형의 신고를 댓글 탭에 섞어 표시하지 않는다.

## 2026-11-27 연결 보완

- 최신 develop 5f1e66f(#177·#181)을 반영했다. 공개 V32(team.deleted_at)는 유지하며 미공개 로컬 마이그레이션은 V33(닉네임 제재), V34(신고 처리 취소 이력)로 배치했다. 서버 DB 적용은 하지 않았다.
- 팀 초대 알림은 InvitationQueryService의 실제 상태를 일괄 조회한다. 없는 초대에 수락·거절 버튼을 표시하지 않는다.
- 관리자 모집글 숨김은 같은 트랜잭션에서 대기 팀 초대를 취소한다.
- TeamDeletedEvent는 AFTER_COMMIT·REQUIRES_NEW로 받아 일정·마감 대기 예약을 취소한다. 발송·예약 보정 단계에서도 TeamService.isDeleted를 확인한다.
- #183(94b06d8) 반영으로 TeamDeleteService의 모집글 마감 호출이 연결되었다.

## 관리자 연결 점검 잔여 항목

- 계정 상태 조회 결과의 role·nickname·profileImageUrl을 로그인 상태에도 동기화한다(30초 조회 및 창 복귀). 신고 대상은 제목 우선 표시, 상세 조회 재시도 버튼 제공.
- 관리자 권한은 V35 초대 수락 절차로 변경했다. 대상자 본인이 수락한 뒤 ADMIN이 되고, 신규 관리자를 제외한 기존 관리자에게 ADMIN_GRANTED를 발송한다. V36 활동 로그에는 초대·수락·권한 부여를 기록한다.
- 신고 처리 취소는 V34 적용이 필요하고, 닉네임 영구 금지는 V33 적용이 필요하다. 로컬 코드 변경과 서버 배포 완료를 구분한다.
