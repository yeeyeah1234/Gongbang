# #117 모바일·태블릿 대응

기준: archive STYLE_GUIDE 8. 이번 변경은 로컬 작업이며 새 PR·배포는 수행하지 않는다.

## 이미 develop에 반영
- #120 공통 URL 검사: global.validation.UrlPolicy.validateOrNull. HTTP(S) 대소문자 무관, URI 호스트 필수, 빈 값 null, 앞뒤 공백 제거. #133 병합 완료.
- post·board URL 검사는 공통 정책으로 전환됨. ContestBatchItem.homepageUrl의 기존 @Pattern은 담당자 후속 전환 대상.
- NotificationBell: 640 미만 화면 좌우 16px 고정, 동적 뷰포트 높이 제한과 목록 스크롤.
- UserMenu compact: 768 미만 닉네임·화살표 숨김. GNB는 옵션을 사용하며 임시 자식 선택자 CSS 없음.

## 이번 로컬 변경
- 관리자 수동 크롤링: 버튼·API·도메인/서비스·worker 제거. 정기 크롤러 유지. V28 및 기존 데이터는 보존.
- 관리자: 1024 미만 목록→선택 상세, 목록으로 복귀. 숨은 상세 컴포넌트/증빙 조회 미실행. 관리 메뉴 접기.
- 마이페이지: 1024 미만 메뉴를 상단에 배치, 좁은 화면 여백, 긴 텍스트 줄바꿈. 내 글 목록은 #144의 카드형 대응 유지.
- 알림 설정: 1024 미만 카드형 목록. 공개 프로필·북마크·알림 전체 화면의 긴 텍스트와 버튼 줄바꿈.
- 로그인·가입·찾기·복원, 프로필 저장·비밀번호 변경·탈퇴, 관리자 주요 폼: 768 미만 하단 주요 버튼과 safe-area 및 본문 여백. desktop에서는 display:contents로 기존 버튼 배치를 유지한다.
- 공통 Modal의 전체 화면 전환은 아직 합의되지 않아 변경하지 않음.

## 확인 범위
- 프런트 build/lint, 백엔드 테스트 및 기존 정기 크롤러 테스트를 실행한다.
- 브라우저 연결이 없어 375/768/1024 실제 화면 캡처와 실회원 API 연동 검증은 아직 미수행이다. 이전 캡처를 이번 변경의 검증 결과로 사용하지 않는다.
